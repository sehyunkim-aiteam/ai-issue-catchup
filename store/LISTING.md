### 상세 설명 (복사해서 붙여넣기)

```
새 탭을 열 때마다, 오늘의 AI 이슈를 따라잡으세요.

AI 이슈 따라잡기는 새 탭 화면에 국내 AI·테크·비즈니스 매체의 최신 소식을 모아 보여줍니다.
따로 사이트를 찾아다니지 않아도, 새 탭 하나로 오늘 나온 AI 소식을 훑어볼 수 있습니다.

■ 주요 기능
· 한국어 AI 뉴스 큐레이션 — AI타임스, 인공지능신문, GeekNews, 블로터, 바이라인네트워크 등 국내 매체 14곳
· 카테고리별 보기 — AI / Vibe Coding / Business / etc
· 인기 콘텐츠 — 여러 매체가 함께 다룬 이슈를 위로
· 썸네일 카드 + 한 줄 요약 — 제목과 첫 문장만으로 빠르게 훑기
· 저장함 — 나중에 읽을 기사를 책갈피로 보관
· 읽은 기사 표시, 라이트/다크 모드, 모바일·태블릿 반응형 웹 제공

■ 업데이트
3시간마다 새 소식으로 자동 갱신됩니다. 확장 프로그램을 업데이트하지 않아도 됩니다.

■ 개인정보
이름·이메일·검색어·다른 사이트 방문 기록은 수집하지 않습니다. 서비스 개선을 위해 새 탭 열기와 기사 클릭 기록만 무작위 식별값과 함께 Google Analytics로 보냅니다. 저장한 기사와 설정은 사용자의 브라우저에만 보관됩니다.

모든 기사의 저작권은 각 매체에 있으며, 카드를 누르면 원문 페이지로 이동합니다.
게시 중단 요청은 지원 페이지(GitHub Issues)로 남겨 주세요.
```

## 개인정보 보호 관행 탭

| 항목 | 입력값 |
|---|---|
| 단일 목적 | 새 탭 페이지를 AI 뉴스 큐레이션 화면으로 바꿔, 국내 매체의 최신 AI·테크 뉴스를 카드 형태로 보여줍니다. |
| `storage` 권한 사유 | 뉴스 피드 캐시(빠른 표시용), 사용자가 저장한 기사, 읽음 표시, 카테고리·화면 모드 설정, 무작위 설치 식별값을 사용자 브라우저에 보관하기 위해 사용합니다. |
| 호스트 권한 | 없음 (요청하지 않음) |
| 원격 코드 사용 | 아니요. 모든 스크립트는 패키지에 포함되어 있으며, 외부에서는 뉴스 데이터(JSON)만 받아옵니다. 사용 기록은 Google Analytics Measurement Protocol로 데이터만 전송합니다(외부 스크립트 로드 없음). |
| 데이터 사용 — 수집 항목 | **사용자 활동**만 체크 (새 탭 열기·기사 클릭 기록) |
| 데이터 사용 인증 3개 | 모두 체크 (판매 안 함 / 핵심 기능 외 사용 안 함 / 신용도 판단 사용 안 함) |
| 개인정보처리방침 URL | https://sehyunkim-aiteam.github.io/ai-issue-catchup/privacy.html |

## 배포 탭
- 공개 범위: 공개 (처음엔 "비공개 — 링크 있는 사용자"로 올려 동작 확인 후 공개 전환도 가능)
- 지역: 전체 또는 대한민국

## 업데이트할 때
1. `extension/manifest.json`의 `version` 올리기 (예: 0.1.0 → 0.1.1)
2. `./package.sh` → 새 zip을 대시보드 "패키지" 탭에 업로드 → 심사 제출
3. 기사 데이터만 바뀌는 건 업데이트 불필요 (feed.json이 3시간마다 자동 갱신)
