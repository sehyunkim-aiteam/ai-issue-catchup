시행일: 2026-11-06 (이전 버전: 2026-11-05, 2026-11-03)

수집하는 정보

서비스 개선을 위해 아래 사용 기록만 Google Analytics 4로 보냅니다. 이름, 이메일, 계정, 검색창 입력 내용, 다른 사이트 방문 기록은 수집하지 않습니다.

  • 새 탭(또는 웹 페이지)을 연 기록
  • 어떤 기사를 어느 영역(인기 콘텐츠·기사 목록·저장한 콘텐츠)에서 눌러 열었는지(기사 식별값)
  • 무작위로 만든 설치 식별값과 세션 식별값 — 처음 열 때 브라우저에서 만들어지며, 사람을 특정할 수 있는 정보와 연결되지 않습니다
  • 사용 환경(확장 프로그램/웹)과 확장 프로그램 버전
  • 확장 프로그램을 설치·업데이트·삭제한 기록과 설치 후 사용 기간(일 단위)
  • 삭제 후 열리는 설문에 답한 경우, 선택한 삭제 이유와 직접 적은 내용(100자 이내) — 답하지 않아도 되며, 이름·연락처는 적지 말아 주세요

수집한 기록은 어떤 기사가 많이 읽히는지 파악해 콘텐츠 구성을 개선하는 데만 쓰며, 판매하거나 광고에 쓰지 않습니다. Google Analytics의 데이터 처리는 Google 개인정보처리방침을 따릅니다.

브라우저에만 저장되는 정보

다음 정보는 사용자의 브라우저(chrome.storage.local)에만 저장되며 외부로 전송되지 않습니다.

  • 뉴스 피드 캐시(빠른 표시용)
  • 사용자가 저장한 기사 목록
  • 읽은 기사 표시(7일 후 자동 삭제)
  • 선택한 탭·필터 설정

확장 프로그램을 삭제하면 위 정보와 설치 식별값도 모두 삭제되고, 다시 설치하면 새 식별값이 만들어집니다.

네트워크 요청

새 탭을 열 때 공개된 뉴스 피드 파일(feed.json) 하나를 GitHub Pages에서 내려받습니다. 이 요청에는 사용자 정보가 포함되지 않습니다. 위 사용 기록은 Google Analytics(google-analytics.com)로 전송됩니다. 확장 프로그램을 삭제하면 크롬이 삭제 설문 페이지(이 사이트의 bye.html)를 새 탭으로 열며, 이때 주소에 설치 식별값·버전·설치 시각이 함께 전달됩니다. 검색창에 입력한 내용은 사용자가 제출할 때만 Google 검색으로 이동하며, 사용 기록에는 포함되지 않습니다.
