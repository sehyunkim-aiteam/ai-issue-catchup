AI 이슈 따라잡기 개인정보처리방침

시행일: 2026-11-03

수집하는 정보

AI 이슈 따라잡기는 개인정보를 수집하지 않습니다. 이름, 이메일, 방문 기록, 검색어, 기기 식별자 등 어떤 정보도 개발자의 서버나 제3자에게 전송하지 않습니다.

브라우저에만 저장되는 정보

다음 정보는 사용자의 브라우저(chrome.storage.local)에만 저장되며 외부로 전송되지 않습니다.

  • 뉴스 피드 캐시(빠른 표시용)
  • 사용자가 저장한 기사 목록
  • 읽은 기사 표시(7일 후 자동 삭제)
  • 선택한 탭·필터 설정

확장 프로그램을 삭제하면 위 정보도 모두 삭제됩니다.

네트워크 요청

새 탭을 열 때 공개된 뉴스 피드 파일(feed.json) 하나를 GitHub Pages에서 내려받습니다. 이 요청에는 사용자 정보가 포함되지 않습니다. 검색창에 입력한 내용은 사용자가 제출할 때만 Google 검색으로 이동합니다.
